# DELETE /v1/blacklists/\{name\}

Elimina una blacklist con **tutti i numeri** che contiene.

<Warning>
Se la blacklist è utilizzata da una o più regole di instradamento, l'eliminazione viene rifiutata con errore `409`. Per forzare comunque l'eliminazione aggiungi il parametro `?force=true` — le regole che la usavano smetteranno di bloccare i numeri.
</Warning>

## Parametri URL

| Parametro | Tipo | Descrizione |
|-----------|------|-------------|
| `name` | string | Nome della blacklist da eliminare |

## Parametri Query

| Parametro | Tipo | Default | Descrizione |
|-----------|------|---------|-------------|
| `force` | boolean | `false` | Se `true`, elimina la blacklist anche se utilizzata da regole di instradamento |

## Richiesta

<CodeGroup>
```bash cURL
curl -X DELETE https://api.mycentralino.com/v1/blacklists/SPAM \
  -H "X-API-KEY: sk_mycentralino_your_api_key"
```

```php PHP
<?php
$ch = curl_init('https://api.mycentralino.com/v1/blacklists/SPAM');
curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_CUSTOMREQUEST => 'DELETE',
    CURLOPT_HTTPHEADER => [
        'X-API-KEY: sk_mycentralino_your_api_key'
    ]
]);

$response = curl_exec($ch);
curl_close($ch);

print_r(json_decode($response, true));
```

```python Python
import requests

headers = {
    'X-API-KEY': 'sk_mycentralino_your_api_key'
}

response = requests.delete(
    'https://api.mycentralino.com/v1/blacklists/SPAM',
    headers=headers
)
print(response.json())
```
</CodeGroup>

## Risposta Successo

`200 OK`

```json
{
  "success": true,
  "data": {
    "name": "SPAM",
    "deleted": true
  }
}
```

## Errori

### 404 - Blacklist non trovata

```json
{
  "success": false,
  "error": "Blacklist non trovata"
}
```

### 409 - Blacklist utilizzata da regole

```json
{
  "success": false,
  "error": "La blacklist e' utilizzata da una o piu' regole di instradamento. Rimuoverla dalle regole oppure ripetere la richiesta con ?force=true.",
  "used_by_rules": ["0612345678"]
}
```

In questo caso puoi:
1. Rimuovere la blacklist dalle regole indicate in `used_by_rules` (dalla dashboard), poi ripetere la richiesta.
2. Forzare l'eliminazione: `DELETE /v1/blacklists/SPAM?force=true`
