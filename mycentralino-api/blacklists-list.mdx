# GET /v1/blacklists

Restituisce l'elenco di tutte le blacklist del centralino, con il numero di voci contenute in ciascuna e le regole di instradamento che le utilizzano.

<Note>
Una **blacklist** è un gruppo di numeri da bloccare, associato alle regole di instradamento del centralino tramite l'azione "Blacklist". Ogni chiamata in ingresso che attraversa la regola viene confrontata con i numeri del gruppo: se corrisponde, viene bloccata.
</Note>

## Richiesta

<CodeGroup>
```bash cURL
curl https://api.mycentralino.com/v1/blacklists \
  -H "X-API-KEY: sk_mycentralino_your_api_key"
```

```php PHP
<?php
$ch = curl_init('https://api.mycentralino.com/v1/blacklists');
curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_HTTPHEADER => [
        'X-API-KEY: sk_mycentralino_your_api_key'
    ]
]);

$response = curl_exec($ch);
curl_close($ch);

print_r(json_decode($response, true));
```

```python Python
import requests

headers = {
    'X-API-KEY': 'sk_mycentralino_your_api_key'
}

response = requests.get(
    'https://api.mycentralino.com/v1/blacklists',
    headers=headers
)
print(response.json())
```
</CodeGroup>

## Risposta Successo

`200 OK`

```json
{
  "success": true,
  "data": [
    {
      "name": "SPAM",
      "numbers_count": 12,
      "used_by_rules": ["0612345678"]
    },
    {
      "name": "CALL_CENTER",
      "numbers_count": 3,
      "used_by_rules": []
    }
  ],
  "count": 2
}
```

## Campi Risposta

| Campo | Tipo | Descrizione |
|-------|------|-------------|
| `name` | string | Nome della blacklist |
| `numbers_count` | int | Numero di voci contenute nella blacklist |
| `used_by_rules` | array | Numerazioni le cui regole di instradamento utilizzano questa blacklist |

## Note

- Una blacklist con `used_by_rules` vuoto esiste ma non è ancora attiva su nessuna regola: i suoi numeri non vengono bloccati finché la blacklist non viene associata a una regola dalla dashboard.
- Per ottenere i numeri contenuti in una blacklist usa [GET /v1/blacklists/\{name\}](/mycentralino-api/blacklists-detail).
