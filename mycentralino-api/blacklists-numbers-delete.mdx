# DELETE /v1/blacklists/\{name\}/numbers/\{id\}

Rimuove un numero da una blacklist. Il numero non viene più bloccato dalle regole che utilizzano la blacklist.

## Parametri URL

| Parametro | Tipo | Descrizione |
|-----------|------|-------------|
| `name` | string | Nome della blacklist |
| `id` | int | ID del numero da eliminare |

## Richiesta

<CodeGroup>
```bash cURL
curl -X DELETE https://api.mycentralino.com/v1/blacklists/SPAM/numbers/4521 \
  -H "X-API-KEY: sk_mycentralino_your_api_key"
```

```php PHP
<?php
$ch = curl_init('https://api.mycentralino.com/v1/blacklists/SPAM/numbers/4521');
curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_CUSTOMREQUEST => 'DELETE',
    CURLOPT_HTTPHEADER => [
        'X-API-KEY: sk_mycentralino_your_api_key'
    ]
]);

$response = curl_exec($ch);
curl_close($ch);

print_r(json_decode($response, true));
```

```python Python
import requests

headers = {
    'X-API-KEY': 'sk_mycentralino_your_api_key'
}

response = requests.delete(
    'https://api.mycentralino.com/v1/blacklists/SPAM/numbers/4521',
    headers=headers
)
print(response.json())
```
</CodeGroup>

## Risposta Successo

`200 OK`

```json
{
  "success": true,
  "data": {
    "id": 4521,
    "deleted": true
  }
}
```

## Errori

### 404 - Numero non trovato

```json
{
  "success": false,
  "error": "Numero non trovato in questa blacklist"
}
```

## Note

- L'eliminazione dell'ultimo numero **non** elimina la blacklist: il gruppo resta disponibile (vuoto) e può essere ripopolato in qualsiasi momento.
- Per eliminare l'intera blacklist usa [DELETE /v1/blacklists/\{name\}](/mycentralino-api/blacklists-delete).
