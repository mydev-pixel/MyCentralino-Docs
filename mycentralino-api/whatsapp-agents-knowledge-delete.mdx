# DELETE /v1/whatsapp/agents/\{id\}/knowledge/\{doc\}

Toglie un documento dalla [conoscenza](/mycentralino-api/whatsapp-agents-knowledge) dell'agente: un testo, una domanda frequente o un file. Dal messaggio successivo l'agente non lo usa più.

<Warning>
Non si può annullare. Un file tolto va ricaricato dal pannello.
</Warning>

## Parametri

| Parametro | Tipo | Obbligatorio | Descrizione |
|-----------|------|--------------|-------------|
| `id` | int | ✅ | ID dell'agente, nel percorso |
| `doc` | int | ✅ | ID del documento, nel percorso |

## Richiesta

<CodeGroup>
```bash cURL
curl -X DELETE "https://api.mycentralino.com/v1/whatsapp/agents/7/knowledge/31" \
  -H "X-API-KEY: sk_mycentralino_your_api_key"
```

```php PHP
<?php
$ch = curl_init('https://api.mycentralino.com/v1/whatsapp/agents/7/knowledge/31');
curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_CUSTOMREQUEST => 'DELETE',
    CURLOPT_HTTPHEADER => ['X-API-KEY: sk_mycentralino_your_api_key']
]);
$response = curl_exec($ch);
curl_close($ch);
print_r(json_decode($response, true));
```

```python Python
import requests

headers = {'X-API-KEY': 'sk_mycentralino_your_api_key'}
response = requests.delete('https://api.mycentralino.com/v1/whatsapp/agents/7/knowledge/31', headers=headers)
print(response.json())
```
</CodeGroup>

## Risposta

`200 OK`

```json
{
  "success": true,
  "data": {
    "id": 31,
    "deleted": true
  }
}
```

Ripetere la chiamata sullo stesso documento risponde `404 knowledge_not_found`. Se il tuo programma ripete le richieste dopo un errore di rete, trattalo come un esito positivo.

Ogni rimozione lascia una riga nel Log attività del pannello, con il titolo del documento.

## Errori

### 404 - agent_not_found
Non c'è un agente con questo `id` su questo account.

### 404 - knowledge_not_found
Non c'è un documento con questo `doc` per questo agente, oppure è già stato tolto.

Gli errori comuni a tutte le rotte sono nell'[introduzione](/mycentralino-api/whatsapp-introduction#codici-di-errore).
