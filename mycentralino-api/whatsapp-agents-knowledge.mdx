# GET /v1/whatsapp/agents/\{id\}/knowledge

La **conoscenza** è ciò che l'agente sa della tua azienda: orari, servizi, prezzi, procedure. A ogni messaggio l'agente cerca nei documenti le parti utili alla domanda del cliente e risponde basandosi su quelle.

Ci sono tre tipi di documento:

| Tipo | Cos'è | Dall'API |
|------|-------|----------|
| `text` | Un testo con un titolo | Si legge, si [aggiunge](/mycentralino-api/whatsapp-agents-knowledge-add), si [riscrive](/mycentralino-api/whatsapp-agents-knowledge-update), si [toglie](/mycentralino-api/whatsapp-agents-knowledge-delete) |
| `faq` | Una domanda frequente con la sua risposta | Si legge, si aggiunge, si riscrive, si toglie |
| `file` | Un file caricato dal pannello (PDF, Word…), di cui si legge il testo estratto | Si legge e si toglie. Si carica solo dal pannello |

Questa rotta elenca i documenti senza il contenuto. Il contenuto di un documento si legge con [`GET /v1/whatsapp/agents/{id}/knowledge/{doc}`](#un-documento).

## Parametri

| Parametro | Tipo | Obbligatorio | Descrizione |
|-----------|------|--------------|-------------|
| `id` | int | ✅ | ID dell'agente, nel percorso |

<CodeGroup>

```bash cURL
  -H "X-API-KEY: sk_mycentralino_your_api_key"
```


| Campo | Tipo | Descrizione |
|-------|------|-------------|
| `documents[].id` | int | ID del documento |
| `documents[].type` | string | `text`, `faq` oppure `file` |
| `documents[].title` | string | Il titolo. Per una FAQ è la domanda |
| `documents[].chars` | int | Quanti caratteri occupa |
| `documents[].file_name` | string \| null | Solo per i file: il nome del file caricato |
| `documents[].created_at` | string | Quando è stato aggiunto, ISO 8601 con fuso |
| `totals` | object | Documenti e caratteri dell'agente, in tutto |
| `limits` | object | Il massimo per agente: 20 documenti e 200.000 caratteri |

## Un documento

### GET /v1/whatsapp/agents/\{id\}/knowledge/\{doc\}

Restituisce un documento con il suo contenuto: gli stessi campi dell'elenco, più il contenuto secondo il tipo.

| Tipo | Campi in più |
|------|--------------|
| `faq` | `question`, `answer` |
| `text` | `text` |
| `file` | `text`: il testo estratto dal file, quello che l'agente legge |

```bash
curl "https://api.mycentralino.com/v1/whatsapp/agents/7/knowledge/31" \
  -H "X-API-KEY: sk_mycentralino_your_api_key"
```

```json
{
  "success": true,
  "data": {
    "id": 31,
    "type": "faq",
    "title": "Che orari fate?",
    "chars": 72,
    "file_name": null,
    "created_at": "2026-11-12T18:25:10+01:00",
    "question": "Che orari fate?",
    "answer": "Dal lunedì al venerdì dalle 9 alle 18, il sabato dalle 9 alle 13."
  }
}
```

## Errori

### 404 - agent_not_found
Non c'è un agente con questo `id` su questo account.

### 404 - knowledge_not_found
Non c'è un documento con questo `doc` per questo agente.

Gli errori comuni a tutte le rotte sono nell'[introduzione](/mycentralino-api/whatsapp-introduction#codici-di-errore).
